# 特征处理流程：从配置到模型输入

本文档详细描述 TorchEasyRec 中特征从配置文件定义到最终进入模型前向传播的完整数据流。

## 概览

```
Proto 配置文件 (.config)
    │
    ▼
┌─────────────────────────┐
│  1. FeatureConfig        │  定义特征类型和参数（embedding_dim, boundaries 等）
│     → Feature 对象        │  每个 Feature 对象计算自己的 output_dim
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│  2. FeatureGroupConfig   │  将多个特征分组，决定哪些特征 concat 到一起
│     → EmbeddingGroupImpl │  累加组内所有 output_dim → group_total_dim
│     或 SeqEmbGroupImpl   │  序列特征拆分为 query / sequence 两条路径
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│  3. Model.init_input()   │  创建 EmbeddingGroup，注册所有 embedding 参数
│     → EmbeddingGroup     │  提供 group_total_dim() / group_feature_dims() 接口
└───────────┬─────────────┘
            │
            ▼
┌─────────────────────────┐
│  4. Model.build_input()  │  运行时：embedding lookup + concat
│     → Dict[group_name,   │  → {"all": Tensor[batch_size, group_total_dim]}
│         Tensor]           │  序列特征额外经过 SeqEncoder 压缩
└─────────────────────────┘
```

---

## 1. FeatureConfig → Feature 对象

### 配置格式

每个 `feature_configs` 条目创建一个 Feature 对象。支持的特征类型：

| 类型 | 配置关键字 | output_dim 计算方式 |
|------|-----------|-------------------|
| **IdFeature** | `id_feature` | `= embedding_dim` |
| **RawFeature** | `raw_feature` | `= len(boundaries) + 1`（分桶），或 `embedding_dim`（指定时） |
| **ComboFeature** | `combo_feature` | `= embedding_dim` |
| **LookupFeature** | `lookup_feature` | `= len(boundaries) + 1` |
| **SequenceFeature** | `sequence_feature` | 子特征维度之和（见序列特征章节） |

### 示例

```protobuf
# IdFeature: embedding_dim 直接决定 output_dim
feature_configs {
  id_feature {
    feature_name: "mmb_id"
    embedding_dim: 32
    hash_bucket_size: 2529348
  }
}
# → output_dim = 32

# RawFeature: boundaries 分桶，output_dim = len(boundaries) + 1
feature_configs {
  raw_feature {
    feature_name: "current_price"
    embedding_dim: 8
    boundaries: 1.99
    boundaries: 5.29
    boundaries: 8.69
    ...
  }
}
# → boundaries 有 18 个 → output_dim = 19
```

### 关键代码

- 特征注册：`tzrec/features/` 下各 Feature 类，通过 `@BaseFeature.register()` 装饰器注册
- `output_dim` 属性：每个 Feature 对象提供，后续维度计算的基础

## 2. FeatureGroupConfig → EmbeddingGroupImpl（维度聚合）

### 配置格式

`feature_groups` 将多个特征归到一个组，决定哪些特征 concat 到一起：

```protobuf
feature_groups {
  group_name: "all"
  feature_names: ["mmb_id", "item_id", "page", "current_price", ...]
  group_type: DEEP    # DEEP | WIDE | SEQUENCE | JAGGED_SEQUENCE
}
```

### 维度计算逻辑

在 `EmbeddingGroupImpl.__init__`（`tzrec/modules/embedding.py` L656-745）中：

```python
for feature_group in feature_groups:
    total_dim = 0
    feature_output_dims = OrderedDict()   # {feature_name: output_dim}

    for name in feature_names:
        feature = name_to_feature[name]
        output_dim = feature.output_dim    # 来自第 1 步
        total_dim += output_dim            # 累加
        feature_output_dims[name] = output_dim

    self._group_total_dim[group_name] = total_dim
    self._group_feature_output_dims[group_name] = feature_output_dims
```

### 运行时 embedding 流程

**IdFeature（稀疏特征）**：
```
输入: 哈希后的整数 ID [batch_size]
  → EmbeddingBagCollection lookup
  → Tensor[batch_size, embedding_dim]
```

**RawFeature（稠密特征）**：
```
输入: 原始浮点值 [batch_size]
  → Bucketization（按 boundaries 分桶）
  → EmbeddingBagCollection lookup
  → Tensor[batch_size, embedding_dim]
```

**最终 concat**：
```
按 feature_names 顺序 concat 所有 embedding
  → Tensor[batch_size, total_dim]
```

### 关键 API

| API | 返回类型 | 说明 |
|-----|---------|------|
| `group_total_dim(group_name)` | `int` | 组内所有特征维度之和 |
| `group_feature_dims(group_name)` | `Dict[str, int]` | 每个特征的维度 `{fname: dim}` |
| `group_names()` | `List[str]` | 所有组名 |

## 3. Model.init_input() → 创建 EmbeddingGroup

在模型 `__init__` 中调用，创建 embedding 参数并计算维度：

```python
# tzrec/models/rank_model.py L82-93
class RankModel(BaseModel):
    def init_input(self):
        self.embedding_group = EmbeddingGroup(
            self._features,
            list(self._base_model_config.feature_groups),
        )
```

然后在模型 `__init__` 中使用：

```python
# 以 dbmtl_lhuc.py 为例
self.init_input()
self.group_name = self.embedding_group.group_names()[0]
feature_in = self.embedding_group.group_total_dim(self.group_name)  # 总输入维度

# 获取每个特征的单独维度（用于 LHUC bias feature 提取）
all_feature_dims = self.embedding_group.group_feature_dims(self.group_name)
# 返回: {"mmb_id": 32, "item_id": 32, "page": 32, "current_price": 19, ...}
```

## 4. Model.build_input() → 运行时 embedding + concat

### 基本流程

```python
# tzrec/models/rank_model.py L113-130
def build_input(self, batch):
    feature_dict = self.embedding_group(batch)
    # → {"all": Tensor[batch_size, group_total_dim]}
    return feature_dict
```

### EmbeddingGroup.forward 内部流程

```
EmbeddingGroup.forward(batch)
│
├── 普通特征: emb_impl(sparse_kjt, dense_kt, ...)
│   → EmbeddingBagCollection lookup (稀疏) + Dense 处理 (稠密)
│   → concat → {"group_name": Tensor[batch, total_dim]}
│
└── 序列特征: seq_emb_impl(sparse_kjt, dense_kt, seq_dense_features, ...)
    → 返回 query / sequence / sequence_length
    → 经过 SeqEncoder (DIN/Pooling/SelfAttention) 压缩
    → concat 回 group_name
```

### 模型中的使用

```python
# dbmtl_lhuc.py predict()
grouped_features = self.build_input(batch)
net = grouped_features[self.group_name]  # Tensor[batch_size, total_dim]
```

## 5. 序列特征处理流程（详细）

序列特征比普通特征复杂，需要额外经过 SeqEncoder 处理。

### 5.1 配置

序列特征需要 3 个配置协同：

```protobuf
# 1. 定义序列特征（用户行为序列）
feature_configs {
  sequence_feature {
    sequence_name: "user_click_seq"
    sequence_length: 50
    sequence_delim: ";"
    features {
      id_feature { feature_name: "click_item" embedding_dim: 32 }
    }
    features {
      raw_feature { feature_name: "click_time" embedding_dim: 8 }
    }
  }
}

# 2. feature_groups 中关联 sequence_groups + sequence_encoders
feature_groups {
  group_name: "user"
  group_type: DEEP
  feature_names: ["user_id", "age"]                    # 普通特征
  sequence_groups {                                     # 序列子组
    group_name: "click_seq"
    feature_names: ["click_item", "click_time"]
  }
  sequence_encoders {                                   # 序列编码器
    din_encoder {
      input: "click_seq"
      attn_mlp { hidden_units: [64] }
    }
  }
}
```

### 5.2 初始化：query / sequence 分离

在 `SequenceEmbeddingGroupImpl.__init__`（`embedding.py` L956-1071）中，特征被分为两类：

```python
for name in feature_names:
    feature = name_to_feature[name]
    if feature.is_sequence:
        # 序列特征（如 click_item 序列）
        sequence_dim += output_dim
    else:
        # 普通特征（如 user_id）
        query_dim += output_dim

self._group_total_dim[f"{group_name}.query"] = query_dim
self._group_total_dim[f"{group_name}.sequence"] = sequence_dim
```

### 5.3 运行时：3D Embedding → SeqEncoder 压缩

```
输入数据:
  user_id:       [batch]              → Embedding → [batch, 32]
  click_item:    [batch, seq_len]     → Embedding → [batch, seq_len, 32]
  click_time:    [batch, seq_len]     → Bucket+Emb → [batch, seq_len, 8]

EmbeddingGroup.forward 输出:
  "user.query"           → Tensor[batch, query_dim]           # 普通特征 concat
  "user.sequence"        → Tensor[batch, seq_len, seq_dim]    # 序列特征 concat (3D!)
  "user.sequence_length" → Tensor[batch]                      # 每个样本的实际序列长度

SeqEncoder (DIN) 处理:
  query + sequence → Target Attention → 加权求和
  → Tensor[batch, seq_dim]  (3D 压缩为 2D)

最终结果:
  "user" = concat(query, seq_encoder_output)
  → Tensor[batch, query_dim + encoder_output_dim]
```

### 5.4 支持的 SeqEncoder 类型

| 编码器 | 配置名 | 核心逻辑 |
|--------|-------|---------|
| **DIN** | `din_encoder` | Target Attention: query 与 sequence 每个位置算 attention score，加权求和 |
| **Pooling** | `pooling_encoder` | Sum/Mean pooling: 直接对序列求均值或求和 |
| **SimpleAttention** | `simple_attention` | 简化版 attention |
| **SelfAttention** | `self_attention_encoder` | Transformer self-attention |
| **MultiWindowDIN** | `multi_window_din_encoder` | 多时间窗口 DIN |
| **HSTU** | `hstu_encoder` | Hierarchical Sequential Transduction Units |

### 5.5 维度汇总

| 阶段 | Key | Shape | 说明 |
|------|-----|-------|------|
| Embedding 后 | `{name}.query` | `[B, query_dim]` | 普通特征 concat |
| Embedding 后 | `{name}.sequence` | `[B, seq_len, seq_dim]` | 序列特征 (3D) |
| Embedding 后 | `{name}.sequence_length` | `[B]` | 实际序列长度 |
| SeqEncoder 后 | `{name}` | `[B, query_dim + encoder_dim]` | 普通特征 + 编码后序列 concat |

## 6. LHUC 场景中的特征提取

在 DBMTL_LHUC 等模型中，需要从 concat 后的大 tensor 中提取部分特征作为 LHUC gate 的输入。

### 配置

```protobuf
lhuc_gate {
  bias_feature_names: "mmb_id"
  bias_feature_names: "item_id"
  bias_feature_names: "page"
  hidden_units: 64
  hidden_units: 32
}
```

### 维度计算

```python
# dbmtl_lhuc.py __init__
all_feature_dims = self.embedding_group.group_feature_dims(self.group_name)
# → {"mmb_id": 32, "item_id": 32, "page": 32, "current_price": 19, ...}

bias_dim = 0
for fname in lhuc_cfg.bias_feature_names:  # ["mmb_id", "item_id", "page"]
    bias_dim += all_feature_dims[fname]     # 32 + 32 + 32 = 96
```

### 运行时提取

`_extract_bias_features()` 从 concat 后的大 tensor 中按 offset 切片：

```python
# dbmtl_lhuc.py L199-207
def _extract_bias_features(self, net):
    # net shape: [batch, group_total_dim]
    # 按特征顺序遍历，用 offset 切片提取指定特征
    parts = []
    offset = 0
    all_dims = self.embedding_group.group_feature_dims(self.group_name)
    for fname, dim in all_dims.items():
        if fname in self._bias_feature_dims:
            parts.append(net[:, offset : offset + dim])
        offset += dim
    return torch.cat(parts, dim=-1)
    # → [batch, bias_dim]
```

**注意**: bias features 必须在 `build_input()` 之后、模型处理（如 bottom_mlp、dcnv2）之前提取，因为此时 net 还是原始 embedding concat，offset 与 `group_feature_dims` 的顺序一致。

## 7. 完整数据流示例

以 `sorter_dbmtl_lhuc.config` 为例，简化的数据流：

```
配置:
  feature_configs: mmb_id(32) + item_id(32) + page(32) + ... (共 N 个特征)
  feature_groups: { group_name: "all", feature_names: [所有特征] }

↓ init_input()

EmbeddingGroup 创建:
  group_total_dim("all") = 32 + 32 + 32 + ... = D (所有特征维度之和)
  group_feature_dims("all") = {"mmb_id": 32, "item_id": 32, ...}

↓ __init__ 继续构建

LHUCEPGate(input_dim=D_bottom, gate_input_dim=bias_dim)
LHUCPPNet(input_dim=D_bottom, gate_input_dim=bias_dim, hidden_units=[512, 256, 128])
DCNv2(input_dim=D, cross_num=4, low_rank=256)
BottomMLP(input_dim=D, hidden_units=[512, 256, 128, 64])
MMoE(input_dim=128, num_expert=4, expert_hidden=[256])
TaskTower(is_click, hidden=[128, 64, 32])
TaskTower(is_conversion, hidden=[128, 64, 32])

↓ predict(batch)

build_input(batch) → {"all": Tensor[batch, D]}

extract_bias_features(net) → bias_embs [batch, 96]
                             (mmb_id:32 + item_id:32 + page:32)

parallel:
  bottom_mlp(net) → LN → [batch, 64]
  dcnv2(net)      → LN → [batch, D]

concat → [batch, D + 64]

lhuc_ep_scale = lhuc_gate(bias_embs)     → [batch, D+64]  (scale factor)
net = net * lhuc_ep_scale                 → [batch, D+64]  (EP 个性化缩放)

net = lhuc_pp_net(net, bias_embs)         → [batch, 128]   (PP 逐层门控 MLP)

mmoe(net) → expert_mix → [[batch, 256], [batch, 256]]

task_mlp(is_click)(expert_0)      → [batch, 32]
task_mlp(is_conversion)(expert_1) → [batch, 32]
relation_mlp(concat)              → [batch, 32]

linear → logits [batch, 2]
```
